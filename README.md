# ⚖️ LegalEase

> **AI-Powered Multilingual Legal Document Intelligence Platform**

LegalEase is a full-stack AI-powered platform that helps users understand complex legal documents by generating simple-language summaries, clause explanations, risk insights, missing-clause detection, document health reports, multilingual translations, and document-based conversations.

---

## 🚀 Features

* 🔐 Secure User Authentication (JWT)
* 📄 Upload & Analyze Legal PDF Documents
* 🧠 AI-Powered Document Classification
* 📝 Plain-Language Document Summaries
* 📑 Important Clause Detection & Explanation
* ⚠️ AI-Powered Risk Detection & 0–100 Risk Score
* 🔍 Missing Clause Detection
* 🩺 Document Health Report
* 🌐 Multilingual Legal Document Translation
* 💬 Document-Based AI Chat / Q&A
* 📄 Page-Aware Analysis & References
* 🎨 Modern Responsive User Interface

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Anuvarshini2212/LegalEase.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder.

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret
GROQ_API_KEY=your_api_key
GROQ_TRANSLATION_MODEL=qwen/qwen3.8-27b
```
